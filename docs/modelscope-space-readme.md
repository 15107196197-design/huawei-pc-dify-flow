# 华为PC营销智能体 · 交互式样机

> 这个空间是**不需要任何配置就能点开体验的演示版**。它展示应用的完整结构（表单、分支、四级方案、讲解模板），但**不调用模型、不读真实资料、不产生真实报价**。

---

## 一、这个演示版能做什么

- 填一张完整的营销任务单：八类场景或自定义、四个平台、目标人群、购买阶段、主要问题、内容目标、修改要求
- 看到"四种方案的对比呈现"长什么样（基准价 / 平台优惠 / 身份权益 / 换新国补）
- 看到"三分钟对客讲解"的六段模板
- 查看、复制、下载 10 份公开提示词原文

## 二、这个演示版**不能**做什么

| 你可能会期待 | 实际情况 |
|---|---|
| 输入真实型号，它给你写一篇文案 | ❌ 不调模型。按钮点了不会生成内容 |
| 输入真实价格，它算出最低实付 | ❌ 不读价格数据，也不做计算 |
| 上传图片让它审 | ❌ 无图源输入 |
| 连你自己的 API Key 进来 | ❌ 没有密钥输入口，也不发任何网络请求 |

**为什么不做这些**：因为"看起来生成了但其实是编的"比"明确告诉你不生成"更糟。这个演示版的原则是——**不伪造生成结果**。

## 四、它原本想解决什么

店员给顾客讲一台 PC，真实的难点不是"写不出漂亮话"，而是三件事：

1. **说不准** —— 型号、配置、适用人群记混
2. **算不对** —— 券能不能叠、国补怎么算、以旧换新折多少，四层优惠很容易算错
3. **不敢承诺** —— 说出去的优惠兑现不了

所以这个作品的设计取向很反直觉：**大部分节点在做"阻止输出"，而不是"生成"**。112 个节点里有 38 个 if-else、37 段门禁代码。缺资料、缺价格、缺少核验，它会停下并告诉你缺什么，而不是给一个听起来合理的答案。
