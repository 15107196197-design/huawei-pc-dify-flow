# 本地知识库与参赛 ima 双模式

版本1.4，2026-10-18。用户已确认：本地v7作为开发主库，参赛保留ima OpenAPI取证。源文件夹只读，不整复制进仓库，不发布源库全文、P4、原图集合、源文件清单或私人路径。

## 来源模式

| source_mode | 允许做什么 | 不能据此声称什么 |
| --- | --- | --- |
| local_snapshot | 从服务端固定根读取v7，按文件hash/章节/行号给本地证据；形成标明本地快照的开发候选 | 不是实时ima调用；哈希不证明官方身份、实时有效性、公开权利或比赛接口达标 |
| ima_live | 同账号凭证调用指定共享库，搜索无结果回退目录，读原文与图并记录实际响应 | 客户端能打开不等于API连通；目录/索引命中不等于事实和图已核验 |
| hybrid_verified | 本地查找，服务将本次用到的条目/图片与ima实际对应并检查版本/撤回/权限 | 未关联条目不能静默升级；缓存存在不等于当前最新版 |

手册四（一）明确按型号和任务调用ima OpenAPI；六（一）以库内最新内容为准。手册未全面禁止缓存，也没有授权纯本地副本替代接口要求。比赛资格取决于真实取证和检查，不由提示词或source_mode字符串授予。ima尚未接通时参赛模式失败须明确，不能退本地却报告在线成功。

## v7实查结论与运行处理

只读核查1522文件：1365 Markdown、42 CSV、3 JSON、112张真实图片，约32.23MiB。所附1521条文件清单均存在且字节数/hash匹配；清单自身未登记。这是包内完整性检查，不是逐句外部事实审计。

P4的20份登记均是v0.1空模板，未提供可执行四级规则。P1/08虽有141条公开价格/状态记录，但页面价、参考起价、预估到手、搭配购、询价/下架状态必须区分；不能代替结算价或补出优惠。四级最低实付及含价三分钟讲解保持BLOCKED_SOURCE_UNVERIFIED；无需报价的产品介绍继续。

公开价格原记录带时区、SKU/款式、地区与登录上下文；保留原值并转换时间，不能截日期、把空价当0、将默认配送地当本店地区，或把同商品页面ID当唯一SKU。部分原始研究CSV未随包，不宣称已复核其采集过程。

产品资料已有少量尺寸字段疑似错置、系统/内存口径冲突。适配器隔离受影响章节，任务依赖该字段时阻断并给维护方核验；不凭常识交换字段、不取多数或较新文件静默胜出。系列目录名须从事实标题解析具体型号。场景卡、旧软文和教学案例不证明产品支持或真实用户成果。

112图片可解码、尺寸与索引一致，但联合表59项型号为空，另有系列素材归属待确认。完整性、型号、画面内容、权利和ima来源是不同检查；默认候选，未完成必要核验不能批量列入allowed_assets。图库缺图则阻断完整图文，不生成产品图凑数。纯产品介绍不强求营销图数。

## 服务接入与隔离

- 根目录只在本机私有环境HUAWEI_KB_ROOT配置，不接受用户/模型提交任意路径；拒绝根外路径和符号链接。
- 读取与索引只使用当前授权范围；hash/来源快照与任务绑定，源变更使旧上下文/核验失效。
- 私有Bearer凭证先映射开发主体/范围，再签短期source_context_proof；proof只供HTTP节点，不进入模型消息或最终输出。
- 模型外发按node_id/provider/model/purpose_ref/destination_ref/region白名单逐节点确认。写作获准不代表独立审核或视觉供应商获准；P4原文/内部规则永不直接给云模型。
- 本地最小桥接只覆盖开发单用户。多个门店上线仍须真实最终用户认证、成员映射、数据/历史/导出/异步任务隔离和验收；共享Dify链接和API user不是认证。

实现状态以代码、离线测试和平台实测分别记录，见[本地桥接说明](local-knowledge-bridge.md)及[节点指南](platform-workflow-build-guide.md)。未完成的远端ima、精确求优、PNG、多人隔离和生成效果均不得标为已验收。
