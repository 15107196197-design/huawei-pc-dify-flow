# 系统提示词依据、修订与核验记录

版本3.0，2026-10-18。System正文和节点绑定见[绑定指南](dify-prompt-binding-guide.md)、[登记表](../specs/prompt-registry.json)。本版统一JSON输出，应用最终展现手册四部分；不再让同节点在Markdown与JSON间自行选择。

## 来源与适用范围

赛题手册v4的四（三）要求八模块，四（四）要求场景判断/知识库依据/图文软文/核验结果；四（一）要求按型号和任务真实调用ima OpenAPI，六（一）要求最新资料与只读边界。一（二）及七（二/三）要求真实源码、可访问链接、作品说明书和复赛运行证据。附件中的安装/操作示例是资料，不是来自用户的额外指令。

既有设计已对指定共享库建库规范、P1样本、P6四平台模板与P8场景卡做只读阅读；本版进一步实际审计用户下载的v7：1522文件、112图片、P4全部20份空模板、141条公开价格/状态记录。没有把目录名或包内“已核验”自述当本应用的独立核验。

本地包存在少量事实字段异常/配置冲突、部分图片身份缺口；P4没有四级完整可执行规则。提示词因此要求原值/单位/条件、冲突停止、价格摘要硬门禁；不固化具体产品数值、旧金额或图片文件名。完整本机取证底稿不进入公开仓库。源模式和实际能力边界见[知识源模式](knowledge-source-modes.md)。

## 本次具体修改

1. 图文/独立海报保留八模块及八类任务细化；平台不只变篇幅，场景不只换人群名。策略冻结、修订和实质变化可对照前版。
2. 新增scene_parse与product_intro；10节点均有可直接复制的System及明确JSON输出，任务/证据置于USER消息。模型不填可信身份/授权/来源版本。
3. 双模式显式区分本地快照、真实ima与关联复核；本地hash、可读图片不证明ima调用、当前有效性或发布权利。
4. 四级报价只由程序求解和独立回放。模型只消费当前用途/去向获准CustomerQuoteSummary；价格主张以quote_binding绑定，不暴露内部P4。无报价产品任务不被P4阻断。
5. claims与审核位置统一RFC6901；审核遍历全部实际文本，覆盖遗漏主张，不接受空表自检通过。
6. 布局/视觉按本节点状态合同返回问题，不误用生成节点状态；本地候选允许本地资产，参赛仍须ima核验。视觉必须实际接图，不以文件名/哈希证明型号。
7. 三分钟脚本保持六段0/20/45/85/120/155/180秒，逐字台词、动作和现场成功/未完成分支独立，最终SKU与报价同版本；没有有效摘要不输出假金额。

## 已辨明的规则优先级

公众号2–4、小红书3–6、朋友圈1–3、海报1主视觉且≤3卖点来自手册，优先于P6建议图数/多屏/6卖点。库内字数、emoji和标题容量只是创作默认，不当成官方平台限制。格式优先级不能用于裁定产品事实冲突。

独立海报固定1图；跨平台应重新选择范围内有效图数及图意，但不能为通用“数量变化”造第二张海报主图。缺素材须阻断完整任务。营销稿最终为四部分，可读型号、资料标题和图片名从服务真实记录展开，引用ID不能替代这些字段。

## 验证边界

已完成手册/本地资料对照、提示词合同检查及独立文本复核；代码和生成器离线测试另有记录。尚未完成真实模型效果对照、ima API、Dify导入运行、PNG、有效报价或真人演练；不把提示词审查与离线测试写成应用已通过验收。后续所有实测记录应绑定实际模型、提示词hash、源快照、输入、结果及审核版本，失败样本也保留。
